# SSC ব্যাচ ২০১৫ — ওয়েবসাইট সেটআপ গাইড

সাইটটা সম্পূর্ণ রেডি। শুধু নিচের ধাপগুলো ফলো করে **`assets/js/config.js`** ফাইলে কিছু ভ্যালু বসাতে হবে — কোনো কোড লেখা লাগবে না।

---

## ধাপ ১ — Friends Google Sheet বানাও

1. একটা নতুন Google Sheet খোলো।
2. প্রথম সারিতে (header) ঠিক এই নামে কলাম বানাও (ছোট/বড় হাতের অক্ষরে সমস্যা নেই):

   | Name | Photo | Position | Location | Phone | Email | Facebook | Instagram | Whatsapp | Group | Birthday | Status |
   |---|---|---|---|---|---|---|---|---|---|---|---|

   - **Photo**: GitHub-এ রাখা ছবির ফাইলের নাম (যেমন `rafi.jpg`) — অথবা পুরো লিংক।
   - **Phone**: `+8801XXXXXXXXX` ফরম্যাটে দিলে SMS/Call বাটন কাজ করবে।
   - **Whatsapp**: খালি রাখলে Phone নাম্বার দিয়েই WhatsApp লিংক অটো বানিয়ে নেবে।
   - **Facebook / Instagram**: পুরো প্রোফাইল লিংক (`https://facebook.com/...`)।
   - **Group**: ঐচ্ছিক — সেকশন/শাখা (A, B, Science, Commerce...) দিলে ফিল্টার করা যাবে।
   - **Birthday**: ঐচ্ছিক, ফরম্যাট `YYYY-MM-DD` — দিলে জন্মদিন রিমাইন্ডার ফিচার (ধাপ ৬.১-খ) এটা ব্যবহার করে।
   - **Status**: ⭐ অ্যাপ্রুভাল গেট। খালি থাকলে সেই বন্ধুর প্রোফাইল সাইটে দেখাবে **না**। কারো রো-তে ম্যানুয়ালি `1` লিখে দিলে তবেই সেই প্রোফাইল কার্ড `friends.html`-এ দেখা যাবে। শুরুতে যাদের তথ্য নিজে বসাচ্ছো তাদের সবার জন্য এখানে `1` লিখে দাও।
3. উপরে ডানদিকে **Share** বাটনে ক্লিক করো → **General access** কে **"Anyone with the link"** এবং role **"Viewer"** করে দাও। (এটা ছাড়া সাইট ডেটা পড়তে পারবে না)
4. শিটের URL থেকে ID কপি করো:
   `https://docs.google.com/spreadsheets/d/`**`এই লম্বা কোডটা`**`/edit`
5. নিচের ট্যাব বারে তোমার sheet-এ ক্লিক করে URL-এর শেষে `#gid=123456` — এই নাম্বারটাও কপি করো (একটামাত্র ট্যাব হলে `0` থাকবে)।

## ধাপ ১.১ — Friends রেজিস্ট্রেশন ফর্ম চালু করো (নিজস্ব HTML/Bootstrap ফর্ম, Google Form লাগবে না)

`friends.html` পাতায় এখন একটা নিজস্ব HTML/Bootstrap ফর্ম আছে (কোনো Google Form embed না) — কেউ পূরণ করলে সরাসরি ধাপ ১-এর Friends Sheet-এ একটা নতুন row হিসেবে জমা হয়। এটা কাজ করাতে একটা ছোট্ট Google Apps Script ডিপ্লয় করতে হবে (একবারই করলেই হয়):

1. `google-apps-script/Code.gs` ফাইলটা খোলো — পুরো ধাপে ধাপে গাইড `google-apps-script/README.md`-এ আছে। সংক্ষেপে:
   - Friends Sheet খুলে **Extensions → Apps Script**
   - `Code.gs`-এর কোড পেস্ট করে সেভ করো
   - **Deploy → New deployment → Web app** — Execute as: **Me**, Who has access: **Anyone**
   - Deploy করে যে URL পাবে সেটা কপি করো
2. `config.js`-এ `SUBMIT_SCRIPT_URL`-এ এই URL বসাও (ধাপ ৬ দেখো)।
3. এতেই হয়ে গেল — এই একই স্ক্রিপ্ট `tools.html`-এর গ্রুপ পোল ফিচারের ভোটও লিখবে, আলাদা কিছু করতে হবে না।
4. নতুন রেজিস্ট্রেশন জমা হলে Status কলাম ফাঁকা থাকবে — Sheet-এ গিয়ে Status কলামে `1` বসালে তবেই প্রোফাইল কার্ড `friends.html`-এ দেখা যাবে।

## ধাপ ২ — Events Google Sheet বানাও

আরেকটা নতুন Google Sheet বানাও, কলাম:

| EventName | Date | Time | Venue | Description | CoverImage |
|---|---|---|---|---|---|

- **Date**: অবশ্যই `YYYY-MM-DD` ফরম্যাটে (যেমন `2026-12-25`)
- **Time**: `HH:MM` (24 ঘণ্টা ফরম্যাট, যেমন `18:30`), খালি রাখলে ডিফল্ট `10:00` ধরবে
- একই নিয়মে Share → "Anyone with the link" (Viewer) করে দাও এবং Sheet ID + gid কপি করো।

## ধাপ ৩ — GitHub-এ ছবি রাখো

1. একটা GitHub repository বানাও (public হতে হবে)।
2. তার ভেতরে একটা `images` ফোল্ডার বানিয়ে সব বন্ধুর ছবি + ইভেন্টের ছবি আপলোড করো।
3. Raw base URL হবে এইরকম:
   `https://raw.githubusercontent.com/তোমার-ইউজারনেম/রিপোর-নাম/main/images/`

## ধাপ ৪ — মেমোরি গ্যালারির ছবি যোগ করো

`assets/js/gallery.js` ফাইল খোলো, `GALLERY_IMAGES` লিস্টে একেকটা ছবির জন্য একটা লাইন যোগ করো:

```js
{ src: "farewell-01.jpg", caption: "বিদায় অনুষ্ঠান, ২০১৫", tag: "Farewell" },
```

## ধাপ ৫ — EmailJS দিয়ে "সবাইকে মেইল" ফিচার চালু করো

1. [emailjs.com](https://www.emailjs.com) এ ফ্রি অ্যাকাউন্ট খোলো।
2. **Email Services** → নিজের Gmail/Outlook যোগ করে একটা **Service ID** পাবে।
3. **Email Templates** → নতুন টেমপ্লেট বানাও, ভেতরে এই ভ্যারিয়েবলগুলো ব্যবহার করো:
   - `{{to_name}}`, `{{to_email}}`, `{{subject}}`, `{{message}}`
   - Template-এর "To Email" ফিল্ডে `{{to_email}}` বসাও।
4. **Account → General** থেকে তোমার **Public Key** কপি করো।
5. এই তিনটা জিনিস — Service ID, Template ID, Public Key — বসাও `config.js` তে।

⚠️ ফ্রি EmailJS প্ল্যানে মাসে একটা লিমিট আছে (আপডেট জানতে emailjs.com-এর pricing পেজ দেখো)। ব্যাচ বড় হলে লিমিট বাড়াতে পেইড প্ল্যান লাগতে পারে।

## ধাপ ৬ — `config.js` এ সব বসাও

`assets/js/config.js` খুলে এই লাইনগুলো নিজের ভ্যালু দিয়ে বদলাও:

```js
FRIENDS_SHEET_ID: "...",
FRIENDS_SHEET_GID: "0",
EVENTS_SHEET_ID: "...",
EVENTS_SHEET_GID: "0",
GITHUB_IMAGE_BASE: "https://raw.githubusercontent.com/username/repo/main/images/",
EMAILJS_PUBLIC_KEY: "...",
EMAILJS_SERVICE_ID: "...",
EMAILJS_TEMPLATE_ID: "...",
SUBMIT_SCRIPT_URL: "...",       // Apps Script Web app URL (ধাপ ১.১ দেখো) — Friends ফর্ম + গ্রুপ পোল দুটোই এটা ব্যবহার করে
POLL_QUESTION: "...",           // গ্রুপ পোলের প্রশ্ন
POLL_OPTIONS: ["...", "..."],   // গ্রুপ পোলের অপশনগুলো
POLL_SHEET_ID: "...",           // পোলের ভোট যে শিটে জমা হবে তার ID (Friends Sheet-এর ID দিলেই চলবে)
POLL_SHEET_GID: "0",
```

## ধাপ ৬.১ — নতুন টুলস (ঐচ্ছিক, চাইলে যেকোনোটা স্কিপ করতে পারো)

`tools.html` পেজে এই টুলগুলো আছে। প্রতিটা আলাদা আলাদা কাজ করে — একটা কনফিগার না করলেও বাকিগুলো ঠিকমতো চলবে।

### ক) নোটিশ বোর্ড
নতুন Google Sheet বানাও, কলাম: `Title | Message | Date | Pinned`
(`Pinned` কলামে `yes` লিখলে সেটা উপরে পিন করা থাকবে)
Share → "Anyone with the link" করে ID + gid নাও, `config.js` এ `NOTICES_SHEET_ID` বসাও।

### খ) জন্মদিন রিমাইন্ডার
ধাপ ১-এ Friends শিটে **Birthday** কলাম বানিয়েছোই — ফরম্যাট `YYYY-MM-DD` (যেমন `2001-04-15`), নতুন বন্ধুরাও রেজিস্ট্রেশন ফর্ম থেকে নিজে বসাতে পারবে (ঐচ্ছিক)।
কারো জন্মদিন আজ হলে সাইটের উপরে লাল ব্যানারে সবাইকে দেখাবে, আর tools.html-এ আসছে ১০ জনের লিস্ট দেখাবে। কোনো আলাদা শিট লাগবে না।

### গ) ফান্ড ট্র্যাকার
নতুন Google Sheet বানাও, কলাম: `Name | Amount | Note | Date`
Share করে `config.js` এ `FUND_SHEET_ID` বসাও, আর `FUND_GOAL` এ টার্গেট এমাউন্ট লিখে দাও (যেমন `50000`)। চাইলে `FUND_INFO`-তেও নিজের ভাষায় এক প্যারাগ্রাফ লিখে দিতে পারো — এটা ফান্ড সেকশনের উপরে দেখাবে।
⚠️ এটা শুধু হিসাব **দেখানোর** জন্য — সত্যিকারের টাকা লেনদেন (bKash/Nagad ইত্যাদি) এই সাইটের বাইরে নিজেরা করবে, শুধু কে কত দিলো সেটা এখানে লিখে রাখবে।

### ঘ) মেসেজ ওয়াল / গেস্টবুক
1. একটা Google Form বানাও, দুটো প্রশ্ন রাখো: **Name** আর **Message**।
2. Form-এর **Responses** ট্যাবে ক্লিক করে সবুজ Sheets আইকনে ক্লিক করো — এটা একটা নতুন Response Sheet বানাবে। ওই শিট Share → "Anyone with the link" করে দাও, ID + gid নাও।
3. Form-এর উপরে ডান পাশে **Send** বাটন → `<>` (Embed HTML) ট্যাব → লম্বা `<iframe src="...">` লিংক থেকে শুধু `src="..."` এর ভেতরের URL টা কপি করো।
4. `config.js` এ `GUESTBOOK_FORM_EMBED_URL` (Form-এর embed URL) আর `GUESTBOOK_SHEET_ID` (Response Sheet-এর ID) বসাও।

### ঙ) বিল ভাগাভাগি ক্যালকুলেটর
এটা সম্পূর্ণ ব্রাউজারে চলে, কোনো সেটআপ লাগে না — এমনিতেই কাজ করবে।

### চ) কমিউনিটি লিংক
`config.js` এ `WHATSAPP_GROUP_URL`, `FACEBOOK_GROUP_URL`, `TELEGRAM_GROUP_URL` — যেগুলো তোমার আছে সেগুলো বসাও, বাকিগুলো খালি রাখলে সেই বাটন দেখাবে না।

### ছ) ফান-জোন (২৪টা মজার টুলস + গেম, ৩টা ট্যাবে ভাগ করা)
`tools.html`-এর "ফান-জোন" সেকশনে তিনটা ট্যাব আছে — সবগুলো টুলই সম্পূর্ণ ব্রাউজারে চলে, কোনো Sheet বা `config.js`-এ কিছু বসানো লাগে না:

- **গেম:** টিক-ট্যাক-টো (দুইজন), রক-পেপার-সিজার্স, মেমোরি ম্যাচ, শব্দ সাজাও, ডাইস রোলার, কয়েন টস, রিয়েকশন টাইম টেস্ট, টাইপিং স্পিড টেস্ট, ব্যাচ ট্রিভিয়া কুইজ
- **বন্ধুদের মজা:** র‍্যান্ডম ফ্রেন্ড পিকার ("আজ কে কুইনী", অ্যাপ্রুভড বন্ধুদের লিস্ট থেকে চলে), আজকের খেতাব জেনারেটর, গিফট এক্সচেঞ্জ পেয়ারিং (সিক্রেট স্যান্টা স্টাইল), এটা নাকি ওটা, সত্যি নাকি সাহস, বন্ধুত্বের শতাংশ ক্যালকুলেটর, আইসব্রেকার প্রশ্ন, চাকা ঘোরাও (স্পিন হুইল)
- **রিয়েল-লাইফ টুলস:** বয়স ক্যালকুলেটর, BMI ক্যালকুলেটর, একক রূপান্তরকারী, পাসওয়ার্ড জেনারেটর, স্টপওয়াচ, শব্দ/অক্ষর গণনা, QR কোড জেনারেটর, রিইউনিয়ন কাউন্টডাউন

### জ) বন্ধু রেজিস্ট্রেশন + অ্যাপ্রুভাল
`friends.html`-এর নিচের দিকে একটা নিজস্ব HTML/Bootstrap রেজিস্ট্রেশন ফর্ম আছে (ধাপ ১.১ দেখো কীভাবে চালু করতে হয়)। কেউ ফর্ম পূরণ করলে ডেটা সরাসরি Friends Sheet-এ জমা হয়, কিন্তু Status কলাম খালি থাকা পর্যন্ত সেই প্রোফাইল কারো কাছে দেখা যাবে না। তুমি Sheet-এ গিয়ে যাচাই করে Status-এ `1` লিখে দিলেই প্রোফাইলটা লাইভ হয়ে যাবে — অর্থাৎ পুরো ব্যাপারটা তোমার ম্যানুয়াল অনুমোদনের উপর নির্ভর করে।

### ঝ) গ্রুপ পোল (সবাই একসাথে ভোট দেয়, ফলাফল লাইভ)
`tools.html`-এ "গ্রুপ পোল" নামে আলাদা একটা সেকশন আছে — এটাই সেই ফিচার যেটা পুরো ব্যাচকে এক জায়গায় নিয়ে আসে। যে কেউ, যেকোনো ডিভাইস থেকে ভোট দিলে সেটা শেয়ার্ড Google Sheet-এ জমা হয় আর ফলাফল সবার জন্য একসাথে আপডেট হয়।
1. ধাপ ১.১-এর Apps Script (`SUBMIT_SCRIPT_URL`) সেটআপ করা থাকলেই এটা কাজ করবে — আলাদা কিছু ডিপ্লয় করতে হবে না।
2. `config.js`-এ `POLL_QUESTION` আর `POLL_OPTIONS` বদলে নিজের প্রশ্ন বসাও।
3. প্রথম ভোটেই স্প্রেডশিটে "PollVotes" নামে একটা নতুন ট্যাব অটো তৈরি হবে। সেই ট্যাবে ক্লিক করে URL-এর শেষের `#gid=...` নাম্বারটা কপি করে `config.js`-এর `POLL_SHEET_GID`-এ বসাও (নাহলে ফলাফল সেকশন প্রথম ট্যাবের ডেটা পড়ার চেষ্টা করবে)।
4. একই ব্রাউজারে দ্বিতীয়বার ভোট দেওয়া আটকাতে সাইট লোকালি মনে রাখে কে ভোট দিয়েছে (localStorage) — এটা কড়া সিকিউরিটি না, শুধু casual duplicate ভোট আটকায়।

## সাধারণ সমস্যার সমাধান

- **"বন্ধুদের তালিকা লোড হয়নি" দেখাচ্ছে** → Sheet Share সেটিং "Anyone with the link" করা হয়েছে কিনা, আর Sheet ID/gid ঠিক আছে কিনা চেক করো।
- **কোনো বন্ধু দেখাচ্ছে না, কিন্তু Sheet-এ ডেটা আছে** → Status কলাম চেক করো — যে রো-তে Status খালি বা `1` ছাড়া অন্য কিছু, সেটা সাইটে দেখাবে না। অ্যাপ্রুভ করতে Status = `1` লিখে দাও।
- **রেজিস্ট্রেশন ফর্ম দেখাচ্ছে না** → config.js এ `FRIENDS_REGISTER_FORM_EMBED_URL` বসানো আছে কিনা দেখো (ধাপ ১.১)।
- **ছবি দেখাচ্ছে না** → GitHub repo public কিনা, ফাইলের নাম আর সিটের Photo কলামের নাম হুবহু মিলছে কিনা (বড়/ছোট হাতের অক্ষরসহ) দেখো।
- **মেইল যাচ্ছে না** → config.js এ EmailJS-এর তিনটা key ঠিকমতো বসানো আছে কিনা, আর Friends সিটের Email কলাম ভরা আছে কিনা দেখো। ব্রাউজার Console (F12) খুললে exact এরর দেখা যাবে।
